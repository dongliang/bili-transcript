把 B 站视频
变成能读的文字

字幕、文字稿、AI 总结，一条命令拿走。

零依赖 · 扫码登录 · 纯命令行

npx bili-transcript BV1xx411c7mD --plain

或者全局装：npm i -g bili-transcript　只需 Node 18+，装完不到 100 KB。

它能做什么

  • 把任意 B 站视频的字幕扒成文字，要不要时间戳都行
  • 拿 B 站官方的 AI 视频总结，带章节和时间点
  • BV 号、av 号、完整链接、b23.tv 短链都认
  • 合集视频可以只取某一集（分P）
  • 给 agent 用的 --json 结构化输出

三步开始

# 1. 登一次，以后不用再登
bili login

# 2. 提取文字稿
bili BV1xx411c7mD --plain

# 3. 长视频写进文件再看
bili "https://b23.tv/xxxxx" --plain -o out.txt

出问题了先跑 bili doctor，它会告诉你是接口变了还是该重新登录了。

为什么要登录

B 站的字幕接口现在强制登录。不登的话接口返回的是空数组——看起来像"这视频没字幕"， 其实是被挡住了。所以得先登一次，躲不过去。

登录全程在你自己的机器上完成。
扫码用的是 B 站官方的二维码登录接口（就是网页版"扫码登录"用的那个）， 不经过任何第三方服务器。凭据存在 ~/.config/bili/auth.json，权限 0600。

另外：扫码登录不会把你手机上的 B 站 App 踢下线——同一个账号支持多端同时在线。 实测过，手机上照常用。

命令一览

命令作用
bili <目标>提取文字稿（默认动作）
bili login扫码登录
bili doctor自检：环境 / 凭据 / 接口
bili install-skill装到本地 agent

提取选项

选项作用
--plain只出连续文字，不带时间戳
--json结构化输出，给程序或 agent 解析
-p N取第 N 个分P
--list只列出字幕轨
--summary附带 B 站 AI 总结
-o FILE写入文件

给 agent 用

npx skills add dongliang/bili-transcript

装了之后，Claude Code、Codex 这类 agent 会在你说"这个视频讲了什么"的时候自己调用它。 agent 内部用 --json 拿结构化数据： 

{
  "ok": true,
  "bvid": "BV14Z4R6KEHS",
  "title": "128G 超大内存，密密麻麻全是颗粒",
  "duration": 175,
  "uploader": "韩宇修机",
  "lines": [
    { "from": 0, "to": 1.96, "text": "128G大内存" }
  ]
}

已知限制

字幕是 AI 自动生成的，会有错别字。
实测中 CAMM 被写成 "cam"、信号线阻值 被写成 "信号线组织"、 焊球 被写成 "气球"。专有名词请核实物件丝印或官方资料再引用。
  • 没有字幕轨的视频（纯音乐、MV、CG 常见）拿不到文字——它会明确告诉你，而不是编一段给你
  • 只支持 B 站，其他平台是另一件事
  • 登录会过期（通常几个月），doctor 会提前告诉你

两个刻意的设计

零依赖。 核心只用 Node 内置的 fetch、crypto、fs。 连二维码都是自己实现的（GF(256) 纠错、Reed-Solomon、掩码择优，PNG 也是手写的）—— 代价是 13 KB 代码，换来整包不到 100 KB，而且没有供应链风险。

绝不返回错误数据。 有个旧接口会返回别的视频的字幕——对一条无字幕的 MV 连测 4 次， 拿到 4 段完全无关的内容。这种错用户看不出来，只会觉得字幕莫名其妙。 所以工具宁可报"没有字幕"，也不回退到那个接口。拿到字幕后还会校验末条时间戳贴不贴合视频时长， 不贴合就告警。
